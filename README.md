A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty: a dark lord mid-speech to his chained captive, losing his place, asking the prisoner to hold the quill — the eclipse, the seventh bell, and a kingdom that falls whether anyone kneels or not. The tiredness lives in the pauses and deflections, never in a plain statement of weariness.

## Run it

```sh
python3 main.py
```

This writes the monologue to `/output/entry.txt` (exactly 100 words, 525 characters).
